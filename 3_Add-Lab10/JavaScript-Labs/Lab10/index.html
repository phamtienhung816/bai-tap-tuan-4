Lab 10 – JavaScript 3: jQuery

Dùng thư viện jQuery để chọn phần tử, xử lý sự kiện, thao tác DOM, tạo hiệu ứng và gửi GET request bất đồng bộ.

jQuery được tải từ https://code.jquery.com, nếu CDN lỗi sẽ tự dùng file assets/js/jquery-3.1.1.min.js. Dịch vụ cities.php trong tài liệu chỉ có địa chỉ http:// nên bị trình duyệt chặn trên GitHub Pages (https); bài 10.9–10.10 dùng bản sao dữ liệu assets/data/cities.json.
