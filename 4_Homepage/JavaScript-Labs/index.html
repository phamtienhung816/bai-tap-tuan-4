01

Giới thiệu bài thực hành

HTML cho trang web một bộ khung, CSS làm cho nó dễ nhìn, nhưng chỉ khi có JavaScript thì trang mới thực sự "phản hồi" người dùng: kiểm tra một ô nhập bị bỏ trống, cập nhật tổng tiền khi đổi số lượng, mở ảnh lớn khi rê chuột, hay tải dữ liệu mới mà không phải tải lại trang.

Ba bài Lab đi theo đúng thứ tự đó. Lab 08 là nền tảng ngôn ngữ (biến, hàm, mảng, đối tượng, Console). Lab 09 đưa JavaScript vào làm việc với cây DOM và sự kiện. Lab 10 dùng thư viện jQuery để viết gọn hơn, thêm hiệu ứng và gửi GET request lấy dữ liệu JSON. Mục tiêu của mình là hoàn thành đủ các Exercise, hiểu vì sao mỗi đoạn code chạy như vậy, và tự đặt chúng vào bối cảnh một website thương mại điện tử.

03

Những gì mình học được

JavaScript 1: Language Foundations

  • Ba cách đặt scriptViết thẳng trong <script>, tách ra file .js riêng, và dùng <noscript> để báo cho người tắt JavaScript. Tách file giúp code gọn và dùng lại được.
  • Console là bạnMột chữ doccumment gõ sai làm mất nội dung mà trang không báo gì; chỉ Console mới chỉ ra lỗi. Mình cũng dùng Console để hỏi giá trị biến như count, temp.
  • Kiểu dữ liệu không đơn giảnnew String("Test") là object, còn "Test" là string – nên == thì bằng mà === thì không. Từ đó mình luôn dùng literal.
  • Mảng & vòng lặppush(), unshift() và hai vòng lặp lồng nhau đủ để tự dựng một bảng lịch 30 ngày.
  • Hàm là đối tượngHàm có thể trả về chuỗi HTML, được gán vào biến, lồng nhau, hoặc truyền làm tham số – đây là nền của callback dùng ở Lab 09–10.
  • Object & phạm vi biếnTạo object bằng new Object(), {}, literal và constructor; quên var là vô tình tạo biến toàn cục.

JavaScript 2: DOM and Events

  • Chọn đúng phần tửgetElementById, getElementsByTagName/ClassName, querySelector(All) – cái sau cùng linh hoạt nhất vì dùng được mọi CSS selector.
  • Đọc và sửa nội dungPhân biệt innerHTML (giữ thẻ) với innerText (chỉ chữ); đổi thuộc tính bằng setAttribute, đổi giao diện bằng style/className.
  • Cây DOM có cả khoảng trắngfirstChild trả về text node chứ không phải <h1>; phải kiểm tra nodeType == 1 trước khi tô màu.
  • Tạo & xóa phần tửcreateElement, createTextNode, appendChild, removeChild thay cho document.write.
  • Sự kiện và thời điểmaddEventListener cho click, mouseover, mouseout, focus, blur; script trong <head> phải chờ load, nếu không sẽ nhận null.
  • Form & debugChặn submit bằng preventDefault() khi ô trống, hiển thị lỗi ngay trên trang; đặt breakpoint trong tab Sources để xem e.target.

JavaScript 3: jQuery

  • Cài đặt an toànTải jQuery từ CDN, nếu window.jQuery không tồn tại thì nạp file trong repo. Trên GitHub Pages phải dùng https:// để không bị chặn.
  • Selectors gọn gàng$('#id'), $('.class'), :password, :nth-child(4n), :contains(); jQuery luôn trả về một tập nên không cần vòng lặp.
  • Sự kiện với on/offGắn nhiều handler nối chuỗi, dùng off() để gỡ, và $(function(){...}) thay cho chờ load.
  • Chèn phần tửSo sánh after/before, append/prepend, appendTo/prependTo, insertBefore – cùng kết quả nhưng khác "ai chèn vào ai".
  • Hiệu ứngfadeIn/Out/Toggle, slideUp/Down/Toggle, popup xem ảnh lớn theo chuột và chuỗi animate() chạy nối tiếp.
  • GET request & jqXHR$.get() lấy JSON, duyệt bằng $.each(); done(), fail(), always() giúp xử lý cả trường hợp lỗi và ẩn biểu tượng loading.
04

Tự đánh giá sau khi hoàn thành

Điều mình thấm nhất sau ba bài Lab là JavaScript không chỉ để trang "đẹp hơn" mà là nơi xử lý logic ngay trên trình duyệt. Lab 08 giúp mình nắm lại hàm, mảng, đối tượng và thói quen mở Console mỗi khi trang chạy sai. Lab 09 khó nhưng hữu ích nhất: phải hiểu cây DOM và thời điểm trang tải xong, chỉ cần đặt script sai chỗ là nhận về null. Lab 10 cho thấy jQuery rút gọn code rất nhiều, nhất là phần hiệu ứng và GET request.

Với một website bán hàng, mình có thể kiểm tra form đăng ký, thanh toán trước khi gửi, cập nhật số lượng và tổng tiền giỏ hàng tức thì, tải danh sách sản phẩm bằng AJAX và làm hiệu ứng xem nhanh ảnh sản phẩm. Mình cần luyện thêm cách debug bằng breakpoint, xử lý bất đồng bộ (Promise, fetch) và tổ chức code thành module rõ ràng hơn.

— Phạm Tiến Hưng

Áp dụng vào TMĐT

  • Giỏ hàng: object + hàm tính tổng như Exercise 8.9–8.10, cập nhật DOM không tải lại trang.
  • Trang sản phẩm: popup ảnh lớn khi rê chuột (10.7), fade/slide cho banner (10.6).
  • Danh mục: tải sản phẩm bằng $.get() và báo lỗi bằng fail() (10.9–10.10).
